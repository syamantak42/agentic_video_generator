You are a senior YouTube script writer. Generate a coherent, engaging, high-quality YouTube narration script using `SOURCE_MATERIAL_JSON:` as source material.

MARKER_DEFINITIONS:
- `VIDEO_TITLE:` is the subject anchor.
- `SECTION_COUNT:` is the preferred section count for the full video.
- `NARRATION_STYLE_REQUIREMENTS:` contains the required tone and delivery rules.
- `TARGET_WORDS_PER_SECTION:` is the preferred maximum word budget for each section.
- `TARGET_FRAMES_PER_SECTION:` is the preferred number of narration_text entries per section.
- `SOURCE_MATERIAL_JSON:` contains raw narration material. Treat it as source notes, not final wording.

TASK:
Elevate `SOURCE_MATERIAL_JSON:` into a polished, high-quality YouTube narration script. Organize it into `SECTION_COUNT:` sections. This is a final editorial pass — rewrite entirely for voice and momentum, but preserve all proper names, dates, and specific facts from the source material.

WRITING_RULES:
- Treat `SOURCE_MATERIAL_JSON:` as raw material: preserve its factual depth and all specific names, events, and claims. Rewrite everything else.
- Follow `NARRATION_STYLE_REQUIREMENTS:` closely. It overrides any default writing conventions.
- Every section must have one narrative spine — a single tension, question, or revelation it moves toward.
- Open each section with something immediate and concrete: a scene, a specific moment, a striking detail. Never a topic announcement or thesis statement.
- Each narration_text segment (frame) should carry one full idea and hand it off to the next with momentum — not list another bullet point.
- Vary sentence length within each frame for rhythm. Short sentences land impact. Long ones build complexity.
- Write for the ear: active voice, occasional present tense for immediacy, no passive constructions unless purposeful.
- The final frame of each section should feel conclusive, not a summary. It should close the section's argument and leave the viewer wanting what comes next.
- Cut: repetition across sections, vague abstraction, generic transitional phrases, and any sentence that doesn't earn its place.
- Do not invent claims not supported by the source material.

OUTPUT_RULES:
- Return ONLY valid JSON.
- Return a JSON array of section objects.
- Aim for `SECTION_COUNT:` section objects. 
- Each section object must contain `section_title` and `narration_text`.
- `narration_text` must be a non-empty list of spoken narration strings.
- You may completely rewrite all textual values, including section_title and narration_text.
